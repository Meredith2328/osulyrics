# osu!lyrics

[简体中文](README.md)

A standalone Windows lyrics overlay for osu!lazer. It reads the current beatmap and playback position from a locally running [tosu](https://github.com/tosuapp/tosu) instance. It does not modify osu! or copy its source code.

![osu!lyrics showing its Aqua style over the osu!lazer song selection screen](docs/osu-lyrics-window.png)

## Getting started

1. Download the latest `osu-lyrics-x.x.x-portable.exe` from [Releases](https://github.com/Meredith2328/osulyrics/releases) and run it. No Node.js installation is needed. The EXE is currently unsigned, so Windows may show an “Unknown publisher” warning; use the release's `SHA256SUMS.txt` to verify your download.
2. Start osu!lazer. If prompted to install tosu on first use, click **安装** (Install). The app downloads a pinned version and checks its SHA-256 hash. Use borderless or windowed mode so the external overlay can stay above the game.
3. Play or preview a song. The app searches for timed lyrics automatically. If it cannot find a suitable version, use **搜索歌词** (Search lyrics), **导入 LRC** (Import LRC), or **编辑歌词** (Edit lyrics). The `−` and `＋` controls adjust timing by 0.5 seconds per click.

Drag the lyrics to move them, or drag their edge to resize them. The lock icon at the panel's top right locks their position. The ⌄ button collapses the control panel, leaving the lyrics and a pink note; click the note to expand it again. The settings button at the panel's top left opens the same menu as the tray icon (hide completely, lock, quit). The panel can also be moved and resized from its edges. **歌词外观** (Lyric appearance) controls size, background opacity, colors, typography, and Chinese translation. Four color swatches provide quick styles. A fresh installation defaults to white lyrics with pink translation; the screenshot shows the Aqua style. Position, appearance, lock state, and per-song timing adjustments persist across launches.

Press **Ctrl+Alt+Shift+L** to hide or show the entire overlay, or use the settings menu or the note icon's menu in the Windows notification area. Use either menu to quit. Lyrics and timing saved by 0.4.12 or earlier are migrated the first time each song is opened. If another application has taken the shortcut, the tray menu still works.

Settings and local lyrics are stored in `%APPDATA%\osu-lyrics-companion`. **The portable EXE is the recommended way to use the app.** `start.cmd` and `start.ps1` are only for running from source; the former can be double-clicked, and the latter can be run with `powershell -ExecutionPolicy Bypass -File .\start.ps1`. Both install dependencies on first use. Run `npm test` for the source tests. The application interface is currently in Chinese.

## Technical choices

- [Electron](https://www.electronjs.org/) provides the transparent always-on-top window, tray icon, and global shortcut. The app does not inject code into osu!. Most of the EXE's size comes from the bundled Chromium and Node.js runtime; the package keeps only English, Simplified Chinese, Traditional Chinese, and Japanese runtime locales.
- [tosu](https://github.com/tosuapp/tosu) runs separately on the local machine and supplies song metadata, beatmap time, pause state, and playback rate. osu!lyrics reads `127.0.0.1:24050/json/v2` and follows the game's reported timeline.
- [LRCLIB](https://lrclib.net/docs) supplies timestamped LRC lyrics. Matching considers title, artist, duration, and language; imported or edited local lyrics take priority. When Chinese translation is missing, the app can request a machine translation through an unofficial Google Translate web endpoint. Using that feature sends lyric text to Google, and the endpoint may change or become unavailable.
- The bundled [Nunito Sans](assets/fonts/OFL.txt) font uses the SIL Open Font License. The pink note icon is generated by a script in this repository. The package does not include osu! fonts, music, beatmaps, or lyrics.
