# osu!lyrics

这是独立运行的 Windows 悬浮歌词工具。它通过本机的 [tosu](https://github.com/tosuapp/tosu) 读取 osu!lazer 的谱面与播放时间，不修改游戏，也不需要复制 osu! 源码。

## 启动

优先双击 `dist/osu-lyrics-0.4.6-portable.exe`；它不需要另装 Node.js。源码方式可双击 [启动歌词工具.cmd](启动歌词工具.cmd)。首次运行时如尚未安装 tosu，点击“安装”，工具会下载已固定版本的 tosu 并校验 SHA-256。以后启动时会自动连接或启动已安装的 tosu。

当前新增的粉色音符收起动画和文案仍在源码开发阶段，暂未重新打包。要体验这些改动请运行 [启动歌词工具.cmd](启动歌词工具.cmd)；`dist` 中的 0.4.6 EXE 是上一次打包的版本。

此电脑已安装 Node.js，因此可以直接运行。也可以在项目目录执行 `npm install` 和 `npm start`。

歌词和控制区现在位于**同一个窗口**。点击窗口左上角的粉色音符会收起控制区：面板先在窗口左上角缩入圆点，圆点再竖直移动到歌词左上角；展开时顺序相反。收起后点击音符或歌词可重新展开。控制区会根据屏幕空间从歌词上方或下方展开，歌词本身保持在原处。控制区有歌词、外观和候选歌词视图，内容全部放在窗口内，不使用纵向滚动条。选择歌词版本后若切换到另一首歌，面板会自动回到主界面。

默认只显示歌词文字。未锁定时，短点击歌词会显示可调整的圆角范围；拖动歌词中间只移动位置，拖动圆角范围的边缘手柄才让宽度、高度和字号等比例缩放。滚轮不再缩放，避免移动时误改大小。“歌词外观”里的 `−` / `＋` 可逐级缩放歌词，设置面板中的控件和字号不会随之缩小。点“锁定位置”后，点击歌词仍可展开控制区，但拖动、边缘缩放和外观修改都会被锁住；点“解锁位置”才能继续。

展开设置面板时，可以按住顶部空白标题栏拖动整个窗口（歌词与面板一起移动）；拖动面板边框可以同步缩放面板与歌词。边框的八个方向有调整区域，按钮和其他控件不会触发拖动。面板会守住 500×370 像素的可读下限，避免缩出滚动条；调整后的面板尺寸会与歌词设置一起保存。

按 **Ctrl+Alt+Shift+L** 可完整隐藏／显示悬浮歌词。Windows 通知区域的音符图标右键菜单也有“隐藏osu!lyrics／显示osu!lyrics”“打开小窗口”和“退出”。隐藏 osu!lyrics 不会清除锁定状态或外观配置。小窗口的 × 会退出整个工具。

“歌词外观”可调歌词大小、背景透明度、样式与中文翻译。透明度 100% 表示背景完全透明；纯文字样式没有背景，也没有文字阴影。长句会换行并让歌词区域增高，不再在两侧显示省略号。首次展开时面板宽度随歌词变化，通常为 560–720 像素；之后可从边框单独调整。位置、样式、面板尺寸、锁定、显示和控制区展开状态保存在 `%APPDATA%\osu-lyrics-companion\windows.json`，重启后继续使用。两页的布局取舍与截图见[界面设计说明](docs/interface-design.md)。视觉参考了 osu!lazer 的[设置界面](https://osu.ppy.sh/home/changelog/lazer/2023.1229.0)及其[官方配色](https://github.com/ppy/osu/blob/master/osu.Game/Graphics/OsuColour.cs)。便携版附带开源的 Nunito Sans 字体；Torus 仅在用户系统已有时使用，未从游戏复制。

把 osu!lazer 设为无边框或窗口模式，歌词窗口会尽量保持置顶。独占全屏可能遮住外部窗口。歌词区域可点击，因此它覆盖的区域会接收鼠标点击；可以拖到不影响打图的位置。

选歌预览状态也会按 osu! 报告的预览时间显示同步歌词；预览早于第一句时不会提前显示未来歌词。没有当前歌词时，悬浮层不显示提示文字或空白背景。

播放位置以 tosu 返回的谱面时间为准。本机每约 100 毫秒读取一次；界面只在确认播放时做短暂插值，暂停和切歌时不自行推进。音频到达总时长或 osu! 进入结果画面后，歌词会收起，时间轴也不会继续超过歌曲总长。

快捷键已按 [osu! 官方默认快捷键表](https://osu.ppy.sh/wiki/en/Client/Keyboard_shortcuts) 和 [osu!lazer 默认绑定源码](https://github.com/ppy/osu/blob/master/osu.Game/Input/Bindings/GlobalActionContainer.cs) 核对。自定义键位或其他软件仍可能占用组合键；若全局注册失败，可用通知区域右键菜单。

## 歌词从哪里来

1. 已保存的本地 LRC 优先使用。
2. 没有本地歌词时，从 [LRCLIB](https://lrclib.net/) 搜索带时间戳的歌词，并按曲名、歌手、音频长度和歌词语言匹配。同名曲存在英日版本时，未明确标为英文版的谱面优先日文歌词；候选列表会显示语言。旧版 LRCLIB 英文缓存会重新复核一次，此后手动选定的版本会保留。版本不确定时会列出候选供手动选择。
3. 若歌词没有中文，工具会尝试机器翻译并明确标注“机器翻译”。翻译服务不可用时仍显示原文。

LRCLIB 繁忙返回 503 时，工具会按服务端给出的等待时间有限次重试；组合搜索仍不可用时先试仅按曲名搜索，再试曲名与歌手的精确查询。若服务持续不可用，可以稍后重搜或导入本地 LRC。歌词查询不会无限重试。

`Gurenge (TV Size)` 这类标题会先试谱面原名，再试去掉 `TV Size` 等版本后缀的曲名；若日文名与罗马字名不同，也会查日文名。候选仍按音频时长筛选，避免把完整歌曲歌词放到短版谱面上。

对于 `Various Artists - ... Starter Pack` 这类合集谱面，工具会从难度名（例如 `Choucho - Ashita no Kimi sae Ireba Ii (_IceRain's 9)`）提取真正的歌手和歌名再搜索。每首歌单独缓存，不会让同一合集里的歌曲互相覆盖歌词。

搜索结果、翻译和校时信息保存在 `%APPDATA%\osu-lyrics-companion\lyrics`。点击“编辑”会打开当前歌曲的 LRC；保存后窗口自动重载。LRC 可以在同一个时间戳下依次写原文和中文：

```lrc
[00:12.50]教えて 教えてよ
[00:12.50]告诉我 告诉我吧
```

点击“导入 LRC”也可以选择已有文件。校时按钮每次调整 0.5 秒，设置会保存在当前歌曲旁边。改速 Mod 会按 tosu 报告的播放倍率计时；若某份歌词文件本身的时间戳有固定偏差，可用校时按钮修正。

## 验证

- `npm test`：解析、双语配对、版本匹配、503 重试和进度状态测试。
- `node scripts/smoke-lyrics.cjs`：联网检查 LRCLIB 检索、歌词缓存与机器翻译，不输出歌词正文。
- `node scripts/smoke-pack.cjs`：联网检查合集谱面难度名解析和同步歌词匹配，不输出歌词正文。

工具在本机 osu!lazer 与 tosu 同时运行时验证过曲目、播放时间及音频总时长。tosu 独立发布，下载来源及版本固定在 `src/main.cjs`，如需更新请重新检查其发布包哈希。
